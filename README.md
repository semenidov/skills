# Skills

Мои персональные скиллы для Codex.

## Скиллы

- [code-reviewer](code-reviewer/SKILL.md) — независимое ревью PR или diff: существенные ошибки, выполнение задания и соблюдение правил проекта.
- [create-pr](create-pr/SKILL.md) — правила оформления draft PR по итогам фичи.
- [ponytail](ponytail/SKILL.md) — минимальное полное решение задачи без лишних усложнений; уровни lite, full и ultra.
- [prepare-dev](prepare-dev/SKILL.md) — проверка готовности окружения перед разработкой.
- [research](research/SKILL.md) — совместная проработка идеи и требований перед реализацией.

## Установка

Склонируй репозиторий:

```sh
git clone https://github.com/semenidov/skills.git
```

Скопируй папки нужных скиллов в каталог персональных скиллов Codex: `$CODEX_HOME/skills` или, при стандартном расположении, `~/.codex/skills` (Windows: `%USERPROFILE%\.codex\skills`). Если папка с таким именем уже существует, сначала сравни содержимое и сохрани нужные локальные изменения.

Каждый скилл находится в отдельной папке; его инструкции и описание — в `SKILL.md`.

Встроенные скиллы `.system` и скиллы установленных плагинов в репозиторий не входят.
